# Projenic Website

Ajans tarzı Projenic web sitesi.

## Yapı
- `index.html` — Ana sayfa
- `style.css` — Stiller
- `assets/images/` — Proje ve atölye görselleri (dhSns.jpg, HESnw.jpg, SuYqm.jpg, GV8Ch.jpg, wBaB0.jpg vb.)

Görselleri `assets/images/` klasörüne yükleyin. Site koyu temalı, ajans havasında kurgulanmıştır.

Canlıya alma: Hostinger veya Netlify/Vercel üzerinden.
